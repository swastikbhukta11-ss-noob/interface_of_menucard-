# 🍷 AURA | Haute Gastronomy Digital Menu Card

A digital menu card frontend with interactive **Mathematical Motion Physics**, 4K food photography, live filtering, and table ordering.

---

## ✨ Features

- **🍽️ Curated 4K Food Photography**:
  - *Crispy Artisan Chicken Burger*
  - *Wood-Fired Margherita Pizza*
  - *Truffled Fettuccine Alfredo*
  - *Decadent Dark Fudge Ganache Cake*
  - *Sparkling Mint Lemonade Cooler*
  - *Truffle & Rosemary Gourmet Fries*
- **🧮 Mathematical Motion Engine & Physics**:
  - **Lissajous Harmonics & Harmonograph Waves**: $x(t) = A \sin(at + \delta) \cos(0.5t), \quad y(t) = B \cos(bt + \phi) \sin(0.3t)$
  - **Lorenz Chaotic Attractor**: Continuous integration of the non-linear 3D attractor.
  - **Keplerian Gravitational Orbits**: $r(\theta) = \frac{a(1 - e^2)}{1 + e \cos(\theta)}$
  - **Rose Curves & Epitrochoids**: $r(\theta) = a \cos(k\theta + \omega t)$
- **🖱️ Real-Time Mathematical Cursor Follower**:
  - Dynamic 28-node spring-mass-damper particle swarm following pointer velocity.
  - Fluid Catmull-Rom sine-wave ribbon trail.
  - Ballistic projectile spark bursts and radial click shockwaves.
- **🎴 3D Card Perspective Tilt**:
  - Euler angles $\theta_x, \theta_y$ and dynamic specular glare based on cursor vector mathematics.
- **🔍 Instant Live Search & Filters**:
  - Real-time search across ingredients, titles, and descriptions.
  - Category tabs & Dietary filters with vibrant Light Green to Blue gradient styling.
- **🛒 Interactive Table Order System**:
  - Quantity steppers, live subtotal, GST (5%), and Service Charge (10%) calculations.
  - Dine-in / Takeaway mode & Digital Kitchen Ticket receipt confirmation.
